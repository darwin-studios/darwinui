# Security

Do not open public issues containing credentials or exploitable private details. Use GitHub private vulnerability reporting if enabled, or contact the repository maintainers privately before sharing reproduction details.

Treat agent output as untrusted data. DarwinUI renders text without HTML execution and accepts only HTTP(S) attachment URLs. Hosts must sandbox creator interfaces and restrict network and tool capabilities. Authentication, authorization, approvals, and tenant isolation remain backend responsibilities.

This is a developer preview, not a security certification. There is no mandatory telemetry.
