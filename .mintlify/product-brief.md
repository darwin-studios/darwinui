# DarwinUI docs brief

Audience: agent developers and host developers using React 19, TypeScript, or JSON-producing backends.
Goal: run a real example, understand Agent/Operation/Thread, embed in an application or compatible MCP host, and connect authorized execution.
Voice: concise, explicit about preview availability. No claims of automatic collaboration, AI generation, publishing, or universal host compatibility.
Source: this public repository. The monorepo contains newer work and is not interchangeable with public package exports.
Site: separate Mintlify project, GitHub darwin-studios/darwinui main, docs directory, intended darwinui.com/docs. Existing Darwin project must remain unchanged.
