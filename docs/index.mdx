---

DarwinUI gives an agent a visual interface for people and a structured representation for agent callers. Build around three concepts: an **Agent** offers **Operations**, and a **Thread** records the work.

<Note>Developer preview. The npm packages are not published yet. Start from the repository using the quickstart.</Note>

Your application supplies execution, persistence, authentication, and authorization. DarwinUI supplies presentation models, validation helpers, and UI components.
