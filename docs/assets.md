# Asset license inventory

The initial public package includes no orb artwork, third-party logos, bundled fonts, or private product imagery. The fallback avatar is a CSS monogram authored in this repository and covered by Apache-2.0. System fonts are referenced, not distributed.

Navigator can supply its own avatar through a React slot; those assets remain outside the public distribution. New assets need source URL, author, license, redistribution rights, and required attribution before inclusion.
